About Gaia

Gaia shows an optical colour map from Data Release 3. Switch between Gaia and SPHEREx to compare the same sky position and zoom. Region and playback tools are available in SPHEREx.

About DSS2 Color

DSS2 Color is an optical composite hosted by MAST at STScI. It uses historical observations from 1975–1999. The viewer checks the currently published map when you select DSS2; it is not live imagery. Switching preserves the sky position and zoom.

About WISE Color

WISE Color is an archived infrared composite from NASA/IPAC IRSA: W4 (22 µm) is red, W2 (4.6 µm) is green, and W1 (3.4 µm) is blue. These are assigned infrared colors. Observation dates come from the archive metadata. This view uses WISE imagery only.
